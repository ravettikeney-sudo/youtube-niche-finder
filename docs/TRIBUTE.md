# Оплата через Tribute и автовыдача ключей

Покупатель оплачивает доступ в Telegram через [Tribute](https://tribute.tg). Наш бот сразу присылает ему ключ. Вам приходит уведомление о покупке. Ничего делать руками не нужно.

```
Сайт «Тарифы» → «Купить» → Tribute (оплата картой)
   → Tribute сообщает нашему серверу о покупке
   → сервер создаёт ключ нужного тарифа
   → бот присылает ключ покупателю в Telegram (и уведомление вам)
```

Всё настраивается на сайте: **«Ключи» → «Автовыдача ключей»**. Там 6 шагов с отметками ✓.

> Названия кнопок в Tribute иногда меняются. Если что-то называется чуть иначе — ищите по смыслу.

---

## Шаг 0. Аккаунт в Tribute (один раз)

1. Откройте в Telegram бота **@tribute** → «Начать» → режим автора.
2. Пройдите регистрацию и укажите, куда выводить деньги (карта или счёт).

Комиссия Tribute — около 10% с платежа. Минимальная цена товара — около 1 евро (~100 ₽).

## Шаг 1. Бот для выдачи ключей

1. Откройте **@BotFather** → команда `/newbot`.
2. Имя — например `Niche Finder`. Ник — например `NicheFinderKeyBot` (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `123456789:AAH…`.
4. На сайте: «Автовыдача ключей» → шаг 1 → вставьте токен → «Подключить». Появится ✓ и ник бота.

Токен — как пароль от бота: никому его не отправляйте.

## Шаг 2. Уведомления вам

Нажмите «Привязать мой Telegram» → откроется ваш бот → нажмите **«Старт»**. Готово: бот будет присылать вам каждую покупку, возврат и всё, что требует внимания.

## Шаг 3. Связь с Tribute

1. В @tribute: панель автора → настройки (⋯) → **«API-ключи»** → создайте ключ.
2. Вставьте его на сайте в шаге 3 → «Сохранить».
3. На сайте нажмите «Скопировать адрес вебхука» — это `https://ytniche.ru/api/tribute/webhook`.
4. В Tribute, там же в разделе API, вставьте этот адрес в поле вебхука (Webhook URL) и сохраните.

Каждое сообщение от Tribute подписано вашим ключом API. Сервер проверяет подпись, поэтому подделать покупку нельзя.

## Шаг 4. Товары → тарифы

Для каждого тарифа сделайте **цифровой товар** в @tribute («Цифровые товары» → «Создать»):

| Поле | Пример для тарифа «Месяц» |
|---|---|
| Название | Niche Finder — доступ на месяц |
| Цена | 1490 ₽ (как на сайте) |
| Описание | Поиск ниш на YouTube, разбор превью и названий, слежение за нишами. 20 анализов в сутки. 30 дней с первого входа. |
| Сообщение после покупки | текст из шага 5 на сайте |

Потом свяжите товары с тарифами. Есть два способа:

- **Ссылкой.** В Tribute: товар → «Ссылки» → скопируйте **ссылку для Telegram** (вида `https://t.me/tribute/app?startapp=p123`). На сайте в блоке «Оплата и тарифы» вставьте её в «Ссылку на оплату» тарифа. ID товара (123) подставится сам. Нажмите «Сохранить тарифы».
- **Списком.** На сайте в шаге 4 нажмите «Загрузить товары из Tribute», выберите тариф для каждого товара и нажмите «Сохранить тарифы».

Берите **ссылку для Telegram**, а не для браузера. Тогда Tribute знает Telegram покупателя, и бот сможет прислать ему ключ. Если человек всё же заплатит в браузере по почте, бот напишет вам, и ключ из уведомления нужно будет переслать вручную.

## Шаг 5. Сообщение после оплаты

Скопируйте текст из шага 5 на сайте. В нём уже стоит ссылка на вашего бота. Вставьте его в каждый товар Tribute как сообщение после покупки. Покупатель откроет бота, нажмёт «Старт» и сразу получит ключ.

Сообщение в товаре Tribute нельзя изменить после создания — только создать товар заново. Поэтому сначала пройдите шаг 1 (чтобы в тексте была ссылка на бота), а потом создавайте товары.

## Шаг 6. Проверка

Выберите тариф и нажмите «Тестовая покупка себе». В бот придут:

- ключ — так его видит покупатель;
- уведомление о покупке — так его видите вы.

Тестовый ключ отмечен «ТЕСТ», его можно удалить в «Ключах».

Для полной проверки купите самый дешёвый тариф сами. Через несколько секунд в бот придёт ключ, а покупка появится в таблице «Покупки» со статусом «✓ доставлен в бот».

---

## Как это работает для покупателя

1. Сайт → «Тарифы» → «Купить» → открывается Tribute в Telegram.
2. Оплачивает картой.
3. Tribute показывает сообщение: «Ваш ключ ждёт в боте…» → покупатель нажимает «Старт».
4. Бот присылает ключ и кнопку «Открыть Niche Finder» — сайт открывается, ключ подставляется сам.
5. Команда `/keys` в боте — все ключи покупателя и сколько осталось времени.

## Что бывает и что делать

| Ситуация | Что произойдёт |
|---|---|
| Покупатель не нажал «Старт» в боте | Ключ ждёт. В «Покупках» статус «ждёт «Старт» в боте». Как только нажмёт — получит. |
| Оплата по почте, без Telegram | Бот пришлёт вам ключ и пометку «отправьте вручную». |
| Товар не привязан к тарифу | Бот пришлёт «Покупка без тарифа». Привяжите товар (шаг 4) и выдайте ключ вручную в «Ключах». |
| Возврат через Tribute | Ключ отзывается автоматически, вам приходит уведомление. |
| Tribute прислал одну покупку дважды | Второй ключ не создаётся. |
| Сервер был недоступен | Tribute повторяет отправку в течение суток. Ключ выдастся, когда сервер ответит. |

# Приём оплаты через Tribute

Покупатель оплачивает доступ в Telegram через [Tribute](https://tribute.tg) и получает ключ. Ключ он вставляет на сайте — и пользуется сервисом.

Схема сейчас такая:

```
Покупатель → страница «Тарифы» → «Купить» → Tribute (оплата картой)
           → Tribute сообщает вам о покупке → вы создаёте ключ в «Ключах» и отправляете приглашение
```

> Названия кнопок в Tribute иногда меняются. Если что-то называется чуть иначе — ищите по смыслу.

## 1. Подключитесь к Tribute (один раз)

1. Откройте в Telegram бота **@tribute** и нажмите «Начать».
2. Выберите режим автора (создателя контента) и пройдите регистрацию.
3. В настройках укажите, куда выводить деньги (карта или счёт). Tribute выплачивает дважды в месяц.

Комиссия Tribute — около 10% с платежа (уточните в самом Tribute). Минимальная цена товара — около 1 евро, поэтому самый дешёвый тариф не должен быть меньше ~100 ₽.

## 2. Создайте товар на каждый тариф

Для каждого тарифа со страницы «Тарифы» сделайте отдельный **цифровой товар** в @tribute: раздел «Цифровые товары» (или «Продукты») → «Создать».

| Поле | Что вписать (пример для тарифа «Месяц») |
|---|---|
| Название | Niche Finder — доступ на месяц |
| Цена | 1490 ₽ |
| Описание | Поиск ниш на YouTube, разбор превью и названий, слежение за нишами. 20 анализов в сутки. Срок 30 дней с первого входа. |
| Сообщение после оплаты | см. ниже |

**Сообщение после оплаты** — его Tribute отправит покупателю сразу после оплаты. Оно одинаковое для всех покупателей, поэтому сам ключ в него вписать нельзя. Напишите так:

```
Спасибо за покупку Niche Finder! 🎉
Ключ доступа придёт вам в этот Telegram в течение 15 минут (днём обычно быстрее).
Если ключ не пришёл — напишите @ВАШ_НИК.
Сайт: https://ytniche.ru
```

После создания товара сообщение нельзя изменить — только создать товар заново. Проверьте текст перед сохранением.

## 3. Вставьте ссылки на сайт

1. В @tribute откройте товар → «Ссылки». Там две ссылки:
   - для Telegram — вида `https://t.me/tribute/app?startapp=p123`;
   - для браузера — вида `https://web.tribute.tg/p/123`.

   Берите ссылку для браузера: она открывается и на компьютере, и на телефоне.
2. Зайдите на сайт как администратор → «Ключи» → блок **«Оплата и тарифы»**.
3. Вставьте ссылку в поле «Ссылка на оплату» нужного тарифа. Там же можно поменять название, срок, лимит, цену и метку («Популярный», «Выгодно»).
4. Нажмите **«Сохранить тарифы»**. Кнопка «Скоро» на странице «Тарифы» сразу станет кнопкой «Купить».

Цены на сайте и в Tribute должны совпадать — меняйте их в обоих местах.

## 4. Когда кто-то купил

Tribute пришлёт вам уведомление о покупке с ником покупателя.

1. Откройте «Ключи» → **«＋ Создать ключ»**.
2. Выберите срок и лимит, как в купленном тарифе. В «Кому» впишите ник покупателя и тариф, например `@ivan — Месяц`.
3. Нажмите «Создать», затем **«✉️ Приглашение»** — текст со ссылкой и ключом скопируется.
4. Отправьте его покупателю в Telegram. Срок ключа начнётся, когда он впервые войдёт.

Если покупатель просит вернуть деньги — возврат делается через поддержку Tribute, а ключ в «Ключах» можно отозвать.

## 5. Следующий шаг — ключ приходит сам

Можно сделать так, чтобы ключ выдавался автоматически, без вашего участия:

- Tribute после каждой покупки сообщает серверу, кто и что купил (это называется вебхук);
- сервер сам создаёт ключ нужного тарифа;
- наш Telegram-бот отправляет ключ покупателю — в сообщении после оплаты будет «нажмите здесь, чтобы получить ключ».

Для этого понадобятся ключ API из Tribute (настройки → «API-ключи») и бот, созданный через @BotFather. Когда будете готовы — скажите, подключим.
